## 🚀 What Each Product Does

### ACT (Agent Coordination Transfer)
**Open Source Coordination Infrastructure**

ACT is the foundational coordination protocol that enables autonomous multi-agent collaboration:

- **Semantic Coordination** - Agents understand context, not just commands
- **PVM Memory System** - Learn from every coordination session
- **Framework Agnostic** - Works with any agent platform
- **Self-Improving** - Gets better with usage via PVM

**Use Cases**:
- Add coordination to existing agent frameworks (CrewAI, LangChain, etc.)
- Build custom multi-agent systems
- Research autonomous agent collaboration
- Educational projects

**License**: MIT (completely free, forever)

---

### AgentMix
**Premium Execution Environment**

AgentMix is the interactive execution environment for ACT-coordinated agent teams:

**Features**:
- **Terminal REPL** - Natural language project commands
- **Real-time Widgets** - SSE-based coordination visualization
- **Session Types** - Projects, Brainstorm, Experiment, Roundtable
- **HITL Controls** - pause, edit, delete, wipe (human-in-the-loop)
- **Improvement Commands** - Surgical precision analysis with /improve
- **ACT Backend** - Full ACT coordination included

**Pricing**:
- **Free Tier**: 3 agents, basic features
- **Pro**: $99/mo - Unlimited agents, all features
- **Enterprise**: $199/mo - Team collaboration, SSO, support

**Use Cases**:
- Professional agent development teams
- Interactive multi-agent projects
- Real-time coordination visualization
- Testing and debugging agent teams

---

### TeamKit
**Model Creation & Merging Toolkit**

TeamKit is a standalone toolkit for creating specialized AI models:

**Features**:
- **Model Management** - Download/cache HuggingFace & Ollama models
- **Model Merging** - DARE, TIES, mergekit techniques
- **Abliteration** - Remove alignment layers (Heretic integration)
- **SmolAgents** - Expert swarm orchestration
- **Custom Fine-tuning** - LoRA and other techniques

**Pricing**:
- **Free Tier**: Basic merging, 3 models
- **Pro**: $99/mo - Unlimited models, advanced techniques
- **Enterprise**: $299/mo - Private registry, team features

**Use Cases**:
- Creating domain-specific models
- Merging expert knowledge
- Building custom agent capabilities
- Experimenting with SLMs

---

### TeamKitOS (TeamKit + ACT)
**The "OS" Transformation**

When TeamKit is combined with ACT (in ACT Studio), it becomes **TeamKitOS**:

**NEW Capabilities**:
- ✨ **Train on PVM Logs** - New models learn from past coordination patterns
- ✨ **Continuous RL** - Models improve through real-time coordination data
- ✨ **Self-Improving Generation** - Each model generation trains the next
- ✨ **Evidence-Based Creation** - Build models based on proven patterns

**The PVM Training Loop**:
```
1. Train new models on EXISTING PVM coordination logs
2. Deploy models to AgentMix (ACT coordinates)
3. PVM records their coordination in real-time
4. Models continuously RL through PVM
5. Future models trained on expanded logs
6. Compounding improvement over generations
```

**Why "OS"**: TeamKit + ACT = Operating System for intelligent agent team creation

---

### ACT Studio
**The Complete Platform**

**ACT Studio = TeamKit + AgentMix**

Since AgentMix includes ACT, combining it with TeamKit gives you all three:

**What You Get**:
- **TeamKitOS** - Create models with PVM training
- **AgentMix** - Test and visualize coordination
- **ACT** - Autonomous coordination infrastructure

**Platform**:
- **Phase 1**: localhost web app (browser-based)
- **Phase 2**: Electron/Tauri desktop app (like LM Studio)

**Complete Workflow**:
```
1. CREATE models in TeamKitOS (trained on PVM logs)
2. TEST teams in AgentMix (interactive REPL)
3. OPTIMIZE via PVM (continuous learning)
4. DEPLOY anywhere (ACT portability)
```

**Pricing**:
- **Professional**: $199/mo (normally $248) - 20% bundle discount
- **Enterprise**: $499/mo (normally $596) - 16% bundle discount

## 💡 Key Innovations

### 1. PVM (PAIRed Vector Minutes)
**Dual-Purpose Semantic Memory**

- **Team Coordination Memory** - What worked, what didn't, why
- **Individual Agent Profiles** - Evidence-based performance tracking
- **Surgical Improvements** - `/improve` command with precision control
- **Self-Learning** - Coordination intelligence improves with usage

### 2. RWKV Long-Context Architecture
**Linear Complexity for 100K+ Token Context**

- Traditional transformers: O(n²) complexity
- RWKV: O(n) complexity
- Full project context always available
- Efficient coordination across large codebases

### 3. Many Experts > One Generalist
**Mathematical Validation**

```
10 specialized 7B models:
- 70B total parameters, 100% effective
- $0.0001/1K tokens
- 50-100 tokens/sec (local)

GPT-4:
- 1.76T total, ~1-5% effective per task
- $0.03/1K tokens (300x more expensive)
- 10-20 tokens/sec (API latency)

RESULT: 4-10x more effective, 300x cheaper, 5-10x faster
```

### 4. Self-Improving Model Generation
**TeamKitOS PVM Training Loop**

- New models train on existing coordination logs
- Bootstrap with proven patterns
- Continuous RL through real-world usage
- Each generation teaches the next
