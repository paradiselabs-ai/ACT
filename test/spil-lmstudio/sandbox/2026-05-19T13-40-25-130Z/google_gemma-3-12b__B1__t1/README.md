# users-api

A minimal user-management API.

## Quickstart
`npm install`
`npm start`

Visit http://localhost:3000/healthz to check if the server is running.

## Endpoints
* GET /healthz - Returns health status.
* GET /users - Returns a list of users.
* POST /users - Creates a new user.
* GET /users/:id - Returns a specific user by ID.

## Testing
`npm test`
